# Phase 1 scope

## Included

- Repository guidance and project directories
- Docker Compose services for PostgreSQL, MongoDB, FastAPI, and React
- Persistent database volumes and service health checks
- FastAPI health endpoints and safe error handling
- Responsive React status dashboard with automatic and manual refresh
- Backend and frontend unit tests
- Environment template and local setup documentation

## Deliberately deferred

Phase 2 owns database models, Alembic migrations, MongoDB collections, sample datasets, generation APIs, and reset APIs. CRUD, query editors, schema diagrams, comparison lessons, transactions, and indexes remain in later phases.
